Why this file is vendored rather than fetched from a CDN
--------------------------------------------------------------------------
The page this replaces loaded NGL from unpkg.com on every request. That put a
third party in the critical path of a MaizeGDB page — the viewer is broken
whenever they are — and disclosed a request from every MaizeGDB reader to a
host with no relationship to this project.

The bundle is served from MaizeGDB instead. Bauplan appends ?v=filemtime() to
the emitted src, so replacing this file busts the cache on its own; no path or
version number has to be edited anywhere else.

To upgrade: replace this file with a current 3Dmol build, keep the name, and
check the viewer against a monomer, a homodimer and a heterodimer. The API
surface used by js/mgdb-protein-structure.js is small and stable —
createViewer, addModel, setStyle/addStyle, addSurface, removeAllSurfaces,
setViewStyle, selectedAtoms, zoomTo, spin, resize, render, pngURI.
